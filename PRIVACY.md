# Privacy Policy — 3SVerse Etsy Tools

**Last updated:** October 19, 2026

3SVerse Etsy Tools is a local-first Chrome extension. It does not require a 3SVerse account, sell data, load remote code, or send analytics or telemetry.

## Local data

The extension stores seed keywords, settings, public research results, reports, trackers, and activity logs in `chrome.storage.local`. Clearing extension data or uninstalling removes it. Exports are created only when a report completes or the user requests a download.

## Pages accessed

Research starts only after a user action. The extension may open and read:

- `etsy.com` public search and listing pages;
- `members.erank.com` only for the optional legacy workflow while the user is logged in and authorized to view that page.

The extension does not bypass authentication, paywalls, access controls, or CAPTCHA.

## Permissions

| Permission | Purpose |
|---|---|
| `storage` | Save local settings and research |
| `tabs` | Open user-requested research pages |
| `scripting` | Support the optional eRank workflow |
| `alarms` | Keep a user-started Manifest V3 research run alive |
| `downloads` | Save reports and exports |

## Third parties

Etsy, eRank, Alura, and EHunt are independent services governed by their own terms and privacy policies. This project is not affiliated with them.
